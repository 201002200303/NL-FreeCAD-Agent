# 电脑鼠标外壳建模技能

> 目标：可识别的鼠标外形——流线壳体、左右对称、前低后高、底部微凹/滑脚、按键分缝感（可选滚轮）。禁止「椭球 + 小盒子」无比例堆叠。

## 0. 默认外形参数（用户未指定时）

以掌心舒适的右手通用尺寸为默认（单位 mm）：

| 参数 | 符号 | 默认 | 说明 |
|------|------|------|------|
| 总长 | L | 110 | X 向前为头、向后为尾 |
| 总宽 | W | 62 | Y，左右对称 |
| 最高高 | H | 38 | Z 向上，峰位约在 0.55L~0.65L |
| 壁厚 | t | 2.0 | 外壳类 |
| 前端高 | H_nose | 18 | 按键区更矮 |
| 底部斜度 | — | 微翘 | 尾部略抬 1~2mm（可选） |

坐标系约定（强制统一，避免零件对不齐）：

- 原点：底面中心投影附近（壳体放在 XY，Z+ 向上）  
- +X：鼠标前方（按键/滚轮端）  
- +Y：用户右侧  
- 左右对称面：XZ 平面（Y=0）

## 1. 推荐阶段划分（start_plan）

1. **P1 主壳体外形**：整体外轮廓实体（对称、流线）  
2. **P2 内腔/抽壳**：壁厚与内部空间（若只要外观实体可声明「实心展示模型」并跳过）  
3. **P3 细节**：滚轮槽、按键分缝、底部滑脚/传感器窗、侧裙倒圆  

成功标准：

- 俯视呈前圆后略收的「水滴/胶囊」轮廓，长宽比约 1.7:1  
- 侧视前低后高，最高点不在正中而偏后  
- 左右关于 XZ 对称  
- 有可见倒圆，无锋利方盒感

## 2. 标准建模工序

### 路线 A（首选：多截面放样 — 最像真鼠标）

1. **定义 4~5 个横向截面**（法向 = X，沿长度分布）  
   建议站点（相对全长）：`x = 0.08L`（鼻）、`0.30L`（按键）、`0.55L`（峰前）、`0.75L`（峰）、`0.95L`（尾）  
   各站：半宽与高度按下表缩放（相对 W/2 与局部高）  

   | 站点 | 半宽系数 | 局部高 |
   |------|----------|--------|
   | 鼻 | 0.70 | H_nose |
   | 按键 | 0.95 | 0.65H |
   | 峰前 | 1.00 | 0.90H |
   | 峰 | 0.95 | H |
   | 尾 | 0.75 | 0.55H |

2. **每个截面**  
   - `create_sketch` 于平行 YZ 的平面（或 XY 画轮廓再摆姿态）  
   - 上半：大半径弧 / 样条；下半：平底或微弧  
   - 左右对称：只画右半再 `mirror`，或整轮廓关于 Y=0 对称约束  
   - 工具：`sketch_add_bspline` / `sketch_add_arc` + `sketch_add_constraint`

3. **放样成实体**  
   `make_loft(name=MouseShell, profiles=[...], solid=true)`  
   截面须同向、不自交；失败则减截面数到 3（鼻/峰/尾）重试。

4. **整体倒圆**  
   `add_fillet` 底边与侧棱，半径 3~6mm（小于局部厚度特征）。

5. **内腔（外观+结构时）**  
   - 缩放/内缩截面再 loft 得 `InnerCore`，或对实体做内缩 boolean  
   - `boolean_cut(MouseShell, InnerCore → MouseBody)`  
   - 保持壁厚 ≈ t；底部可留 1mm 实心底或开传感器窗

### 路线 B（快速示意：球体变形 + 布尔 — 仅用户要「简单鼠标」时）

1. 主身：`create_sphere` 或扁椭（可用 `create_sphere` + `scale` 非等比 → 约 L×W×H）  
2. 前脸：用大半径圆柱/盒 `boolean_cut` 削出按键坡度  
3. 左右 `mirror` 保证对称  
4. 底部切平：`create_box` 做刀具 cut 出平面底  
5. 仍须倒圆，避免「纯椭圆球」

**默认走路线 A**；仅当用户说「简单/示意」才用 B。

### 滚轮与按键（P3）

1. **滚轮槽**：在顶面中线靠前（约 0.35L）  
   - 小圆柱卧倒（轴沿 Y）作刀具，`boolean_cut` 出槽  
   - 滚轮体：小 `create_torus` 或圆柱，置入槽中（装配或同文档摆放）

2. **按键分缝**：窄缝用薄盒 `boolean_cut`，位于鼻部顶面、关于 Y=0 对称两条或一条中缝+左右键

3. **滑脚**：底部四角小 `create_box`/`create_cylinder`（高 0.8~1.2mm），`linear_pattern` 或对称 mirror 布置

4. **传感器窗**（可选）：底面中心小矩形 cut

## 3. 比例与美学约束（「像鼠标」的硬条件）

- 长 : 宽 : 高 ≈ **110 : 62 : 38**（可整体缩放，保持比例）  
- 最高点偏后，禁止「半个鸡蛋直立」  
- 前端宽度略收，禁止正长方体圆角冒充  
- 底面必须可平放（大平面或四脚着地）  
- 对称面清晰；禁止单侧鼓包无镜像

## 4. 硬性禁止

- ❌ 一个球 + 一个小圆柱叫「鼠标」  
- ❌ 长宽高接近正方体  
- ❌ 先随意堆布尔再补对称（应先对称建模）  
- ❌ 壁厚 > 4mm 的「砖头壳」（除非用户要实心手板）

## 5. 工具选择速查

| 意图 | 工具 |
|------|------|
| 截面轮廓 | `create_sketch` + arc/bspline/polyline |
| 主身 | **`make_loft`**（首选）或 sphere+scale |
| 对称 | `mirror` |
| 削面/开槽 | `boolean_cut` |
| 倒圆 | `add_fillet` |
| 滑脚阵列 | `linear_pattern` / `mirror` |
| 姿态核对 | `get_object_detail`, `compare_orientation` |

## 6. 验收清单

1. 三视图可辨：俯视水滴、侧视驼峰偏后、正视左右对称  
2. bbox 长宽高比例接近默认（误差 < 15%，除非用户改尺寸）  
3. 底面 zmin 齐平可放桌面  
4. 若做了内腔：壁厚稳定，无破面
