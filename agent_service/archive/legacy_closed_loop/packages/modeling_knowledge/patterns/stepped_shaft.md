# 阶梯轴建模技能

> 目标：同轴多段圆柱构成的轴类零件——清晰轴肩、合理长短径搭配、端部倒角、可选键槽/退刀槽。禁止多段圆柱错轴心「糖葫芦歪串」。

## 0. 默认参数（用户未指定时）

示例轴（可整体缩放），从左（−X）到右（+X）：

| 段名 | 直径 D (mm) | 长度 L (mm) | 角色 |
|------|-------------|-------------|------|
| A 轴颈 | 20 | 25 | 轴承位 / 输入端 |
| B 轴肩挡 | 28 | 8 | 定位轴肩 |
| C 主体 | 25 | 50 | 过盈/过渡配合段 |
| D 轴肩挡 | 32 | 10 | 大轴肩 |
| E 输出轴颈 | 18 | 30 | 输出端 |
| F 螺纹端（可选） | 16 | 15 | 细端 |

总长 ≈ 各段之和。坐标系：

- **轴心 = X 轴**（圆柱 `rot_y=90°` 或等价，使高度沿 X）  
- 原点取左端面中心或轴中点（全文档统一即可）  
- 各段 **必须同轴**：中心线共线，禁止仅靠目测摆放

过渡：轴肩处外缘 `add_chamfer` 0.5~1mm 或小圆角；配合轴颈端部 0.5×45° 倒角。

## 1. 推荐阶段划分（start_plan）

1. **P1 轴段生成**：按直径从大到小或从左到右生成各段圆柱并保证同轴叠接  
2. **P2 合并为单体**：`boolean_fuse` 成单一 `Shaft`  
3. **P3 工艺细节**：端部倒角、轴肩圆角、键槽、退刀槽、中心孔（按需）

成功标准：

- 唯一主轴心线；各段中心偏移 < 0.1mm  
- 轴肩为垂直台阶（直径突变处平面环）  
- 段数 ≥ 3（否则不像「阶梯」轴）  
- 最终可 `get_object_detail` 看到沿轴向的多级直径变化

## 2. 标准建模工序

### 路线 A（首选：多段圆柱 + 轴向对齐）

1. **逐段创建圆柱**  
   `create_cylinder(name=SegA, radius=D/2, height=L, rot_y=90, pos=...)`  
   注意：Part 圆柱默认轴沿 +Z，故需 `rot_y=90`（或 `rot_x=90`）把轴转到 +X。  
   **全轴统一一种旋转约定，中途不得混用。**

2. **轴向串接（禁止猜绝对坐标瞎摆）**  
   - 第一段放在起点  
   - 后续段：`align_objects(target=SegB, reference=SegA, axis=x, mode=stack)`  
     或 `place_relative` 按端面锚点对接  
   - 保证对接面贴合：前段 max_x ≈ 后段 min_x（间隙 0）  
   - 直径不同时，对齐的是**端面**，不是外圆

3. **同轴校准**  
   每段创建后 `get_object_detail`：中心 Y/Z 应同为 0（或同一常数）。  
   若偏心：`place_relative` / `set_placement` 校正，**禁止**带着偏心继续 fuse。

4. **合并**  
   从左到右两两 `boolean_fuse`，或链式 fuse 得 `Shaft`。  
   命名清晰：`Shaft_AB` → `Shaft_ABC` → … → `Shaft`。

5. **倒角 / 圆角**  
   - 两端外圆边：`add_chamfer` 0.5~1mm  
   - 轴肩内角：小 `add_fillet`（0.3~0.8mm）模拟磨削圆角；过大圆角会吃掉轴肩定位面

### 路线 B（旋转体 — 段数多或有锥度时更干净）

1. `create_sketch` 于 XZ（或 XY）平面  
2. 画轴的**半边轮廓**（阶梯折线）：水平线 = 半径，竖直线 = 轴肩  
3. 封闭轮廓须在轴心线一侧，且与轴线共边或可旋转成实心  
4. `revolve_sketch` / `make_revolve` 绕 X（轴心）360° → `Shaft`  
5. 再加倒角、键槽

段数 ≥ 5 或带锥段时优先路线 B。

### 键槽（常用细节）

1. 确定所在轴段直径 D、键槽宽 b、深 t（未指定时：b≈0.25D，t≈0.12D，长度 ≈ 0.8·该段长）
2. 刀具必须用 **`create_box(..., anchor="center")`**，否则会偏心看起来像「斜槽」  
   - 轴沿 X、键槽开在 +Z 顶面时：  
     `length=键长, width=b, height≈t+余量`  
     `pos_x=槽段轴向中点, pos_y=0, pos_z=r-t/2`（中心落在槽深中线）  
   - **禁止** `anchor=min` 且 `pos_y=0`（角点放置会变成 y=0..b，整槽偏到侧面）
3. `boolean_cut(base=Shaft, tool=KeyCutter)` — 只能 cut，禁止 fuse
4. 不要对整轴 `add_fillet(edge_selector=all)`，会把键槽棱一起糊掉；圆角只点轴肩边
5. 对称双键槽用 `mirror`

### 退刀槽 / 砂轮越程槽（可选）

在轴肩根部用薄圆环或小圆柱 `boolean_cut`，宽度 2~3mm，深度 0.25~0.5mm 量级。

### 中心孔（可选）

两端面中心：小圆柱刀具沿 X 切入 `boolean_cut`，深度 3~5mm，符合机加工中心孔示意即可。

## 3. 设计约束（机械常识）

- **轴肩高度**：(D_大 − D_小)/2 通常 ≥ 1.5mm，过小不像定位肩  
- **长径比**：单段 L/D 常见 0.8~3；细长比过大要分段支撑（建模仍可做，但勿做成面条无肩）  
- **配合段**：轴承位直径常小于邻接挡肩  
- **强度示意**：输出端细、中部粗是常见布局，可按默认表  
- 所有回转面同轴；键槽对称面过轴心

## 4. 硬性禁止

- ❌ 各段中心线不共线仍 fuse（歪轴）  
- ❌ 只用一个圆柱叫「阶梯轴」  
- ❌ 段与段沿径向并排（应是轴向串接）  
- ❌ 轴肩做成斜坡大锥却声称「标准阶梯轴」（除非用户要锥轴）  
- ❌ 忽略旋转方向导致「立柱一排」而非横轴
- ❌ 键槽盒子用角点放置导致偏心（看起来像斜槽）
- ❌ 键槽后对整轴 `fillet all`

## 5. 工具选择速查

| 意图 | 工具 |
|------|------|
| 轴段 | `create_cylinder`（注意 rot 到 X） |
| 轴向对接 | **`align_objects` / `place_relative`** |
| 多段轮廓 | sketch + **`revolve_sketch`/`make_revolve`** |
| 合并 | `boolean_fuse` |
| 键槽/孔 | `boolean_cut` |
| 倒角圆角 | `add_chamfer`, `add_fillet` |
| 同轴检查 | `get_object_detail`, `compare_orientation`, `measure_gap` |

## 6. 验收清单

1. 侧视（Y 向）：台阶轮廓清晰，≥2 个轴肩  
2. 各段 bbox 中心 Y/Z 一致  
3. 总长 ≈ Σ Li；最大直径段可识别  
4. 倒角后端面仍可辨；键槽在直径正确的那段上  

## 7. 与齿轮组合

「齿轮轴」= 本技能阶梯轴 + `gear.md` 齿轮，再 `mate_coaxial` / 布尔融合使齿轮内孔套在对应轴径上。先完成轴与孔尺寸匹配（孔直径 = 配合轴径）。
